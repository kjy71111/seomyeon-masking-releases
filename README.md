# 김사부의 서면 마스킹 — 배포 저장소

법률서면(.hwp · .hwpx · .docx · .pdf · .txt)의 개인정보를 가리는 **무료 체험판 (2027-01-16까지 사용 가능)** 프로그램입니다. **스캔한 PDF(글자 선택이 안 되는 PDF)도 PC 안에서 글자를 읽어 처리합니다.**
만든 사람: 김종엽 변호사 (김사부) · 소개 사이트: https://seomyeon-masking.vercel.app

> 이 저장소에는 **설치 파일과 안내 문서만** 있습니다. 프로그램 소스는 공개하지 않습니다.

## 이번 버전 (v1.3.0)
- **스캔 PDF 지원**: 복합기로 스캔했거나 그림으로만 된 PDF는 Windows에 들어 있는 한국어 문자 인식(OCR)으로 쪽마다 글자를 읽어 가립니다. 읽는 일도 이 PC 안에서만 하고 인터넷·외부 AI를 쓰지 않습니다. 글자가 있는 쪽은 예전처럼 처리합니다.
- **등기부등본 보완**: 등기목적 칸 문장 속 성명, 글자 사이에 공백·줄바꿈이 낀 성명, 소유자·공유자·근저당권자 같은 역할어 뒤 성명까지 인물사전 기준으로 가립니다. 글자층이 성명을 잘못 읽어 빠진 자리는 점검에서 `글자층 오독 - 확정`으로 알려 줍니다.
- 무료 체험 종료일(2027-01-16)·설치 비밀번호 없음·100% 오프라인은 그대로입니다.

- **2027-01-16 23:59(한국 시간)까지** 모든 기능을 무료로 쓸 수 있습니다.
- 체험 기간이 끝나면 **새로 가명처리·비식별처리하는 기능만** 막힙니다. **이미 가명처리해 둔 문서의 실명복원과 점검은 계속 쓸 수 있습니다.** (대응표 …대응표.json은 지우지 말고 보관하세요)
- 다른 분께 알려 줄 때는 설치 파일을 직접 보내지 말고 소개 사이트나 이 저장소 주소를 알려 주세요.

## 설치할 때
1. `SeoMask-v<버전>-win-setup.exe`를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. (코드 서명을 하지 않은 무료 프로그램이라 처음에 뜨는 경고입니다)
3. 이용 안내에 동의하고 설치를 마칩니다. 설치 비밀번호는 없고, 관리자 권한 없이 설치됩니다.

## 파일 위변조 확인 (SHA-256)
내려받은 파일의 값이 Releases에 있는 `SHA256SUMS.txt`의 값과 같은지 확인하세요.

PowerShell:
```powershell
Get-FileHash .\SeoMask-v1.2.1-win-setup.exe -Algorithm SHA256
```
명령 프롬프트:
```bat
certutil -hashfile SeoMask-v1.2.1-win-setup.exe SHA256
```
값이 다르면 실행하지 말고 다시 내려받으세요.

## 알려진 제한
- **스캔 PDF는 글자 인식(OCR)을 거칩니다.** 인식이 틀리면 가림이 빠지거나 다른 글자를 덮을 수 있고, 손글씨·도장·흐린 글자는 읽지 못할 수 있습니다. 읽지 못한 부분은 점검에서 `판정 불가`로 표시되니 그 자리를 눈으로 확인하세요. 한국어 OCR이 설치되지 않은 PC(Windows 설정 > 시간 및 언어 > 언어 및 지역 > 한국어 언어 옵션)에서는 스캔 쪽이 있는 파일을 처리하지 않고 안내합니다. 스캔 쪽이 있는 문서는 처리 시간이 더 걸립니다.
- **.hwp 결과물의 "최종 저장자"**: 한글이 결과 .hwp를 저장할 때 이 PC의 Windows 계정 이름을 다시 기록합니다.
  외부에 공유할 문서는 **한글에서 .hwpx로 저장한 뒤 처리**하면 저장자 정보까지 지워집니다. ([점검]에서도 확인할 수 있습니다)
- 자동 탐지는 보조 수단입니다. 이름의 다른 표기, 합치면 누구인지 알 수 있는 정보, 이미지·스캔 속 글자 등은 놓칠 수 있으니 결과물을 반드시 직접 확인하세요.
